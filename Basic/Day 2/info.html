Evaluation of Website 1. Computer Network – The Beginning The history of a website starts with computer networking. In the beginning, computers worked independently. If a person wanted to share information with another computer, there was no easy way to do it. Therefore, computers began to be connected together through networks. The basic communication was: Computer A → Network → Computer B This was the first important step toward the development of the Internet. 2. ARPANET – 1969 The next major development was ARPANET. ARPANET was created in 1969 as an early computer network. It connected computers in different locations and allowed them to communicate and exchange information. This was not yet the World Wide Web, but it became an important foundation for the Internet. The process was: Computer → ARPANET → Another Computer 3. TCP/IP – Communication System As computer networks increased, different networks needed a common method to communicate. This led to the development and adoption of TCP/IP. TCP – Transmission Control Protocol TCP manages the reliable delivery of data. IP – Internet Protocol IP identifies the destination and helps route data through networks. The process can be understood as: Data → TCP → IP → Network → Destination TCP/IP became one of the fundamental technologies behind Internet communication. 4. Internet When many networks became connected together, the Internet developed. The Internet is a worldwide network of interconnected computer networks. For example: Computer → Local Network → Internet → Server Through the Internet, a computer in one location can communicate with a server in another location. 5. World Wide Web – 1989 The next major stage was the World Wide Web. In 1989, Tim Berners-Lee proposed the World Wide Web. The Web provided a way to access and connect information using documents and hyperlinks. The basic Web technologies were: HTML + HTTP + URL These became the foundation of websites. 6. HTML – Creating the Web Page The next important step was HTML – HyperText Markup Language. HTML is used to create the structure of a web page. For example: HTML

My Website

Welcome to my website.

The browser reads the HTML and displays: My Website Welcome to my website. Therefore: HTML → Creates the structure of the webpage 7. Web Browser After web pages were created, users needed software to view them. That software is called a Web Browser. Examples include: Google Chrome Microsoft Edge Mozilla Firefox Safari When a user enters a website address, the browser requests the required information from a web server. The process is: User → Browser → Internet → Web Server Then: Web Server → Browser → Web Page 8. DNS – Finding the Website When a user enters a domain name such as: example.com the browser needs to find the server's IP address. This is where DNS – Domain Name System is used. The process is: Domain Name → DNS → IP Address → Server DNS helps the browser locate the correct server. 9. HTTP – Request and Response Now the browser needs a communication method to talk to the web server. This is where HTTP – HyperText Transfer Protocol is used. The browser sends a request: Browser → HTTP Request → Server The server processes the request and sends a response: Server → HTTP Response → Browser The browser then displays the webpage. 10. HTTPS – Secure Website Later, website security became very important. HTTPS – HyperText Transfer Protocol Secure provides encrypted communication between the browser and server. The process is: Browser → Secure HTTPS Request → Server Server → Secure HTTPS Response → Browser HTTPS is especially important for login pages, personal information and online transactions. 11. CSS – Website Design HTML created the structure, but websites needed a better appearance. Then CSS – Cascading Style Sheets became important. CSS controls: Colours Fonts Text size Background Spacing Layout Position So: HTML → Structure CSS → Design For example: HTML

Welcome

CSS can change the appearance of the heading. 12. JavaScript – Making Websites Interactive Websites then needed to respond to user actions. JavaScript made this possible. For example: User clicks a button ↓ JavaScript receives the action ↓ JavaScript executes a function ↓ Website output changes JavaScript can be used for: Buttons Menus Forms Calculations Validation Interactive content Therefore: HTML → Structure CSS → Appearance JavaScript → Behaviour 13. Static Website Early websites were mainly static websites. The server already had an HTML file. When the user requested it: Browser → Server ↓ HTML File ↓ Browser ↓ Web Page The content was mostly fixed. 14. Dynamic Website Later, websites became dynamic. A dynamic website can process user requests and generate content using server-side applications. The process becomes: User → Browser → Server → Application → Database The database provides the required information. Then: Database → Application → Server → Browser This made websites more powerful. 15. Database and SQL Dynamic websites need to store information. For example: Student Name Register Number Course Marks This information can be stored in a database. SQL – Structured Query Language is used to work with relational databases. Example: SELECT * FROM students; The database returns the required information to the application. 16. Login System A simple example of a dynamic website is a login system. The user enters: Username + Password ↓ Browser ↓ Server ↓ Database The server checks the information. If it is correct: Database → Server → Browser ↓ Login Successful If it is incorrect: ↓ Login Failed This shows how the frontend, backend and database work together. 17. Web 2.0 Websites then became more interactive. Users were no longer only reading information. They could: Create posts Add comments Upload photos Upload videos Give reviews Create profiles The Web became more interactive and user-oriented. 18. Responsive Web Design Smartphones became popular, so websites needed to work on different screen sizes. A responsive website works on: Desktop ↓ Tablet ↓ Mobile The website automatically adjusts its layout according to the screen size. 19. Modern Website Today, websites are much more advanced. A modern website can have: Frontend HTML + CSS + JavaScript ↓ Backend Java / Python / PHP / Node.js ↓ Database MySQL / PostgreSQL / MongoDB All these components work together to provide the final result to the user. 20. Complete Website Working – Starting to Ending Finally, the complete process is: User ↓ Web Browser ↓ URL ↓ DNS ↓ IP Address ↓ TCP/IP ↓ HTTPS Request ↓ Web Server ↓ Backend Application ↓ Database / SQL ↓ Data Processing ↓ Server Response ↓ HTML + CSS + JavaScript ↓ Browser Rendering
